If a servo stays at an end stop

If the S3-commanded pulse changes but the servo stays pegged, stop the test and check the signal at its connector. Tilt is on GPIO13. At 50 Hz, a 1500 µs command should produce a 1.5 ms high pulse every 20 ms. Software readback cannot confirm the electrical waveform or shaft position.
